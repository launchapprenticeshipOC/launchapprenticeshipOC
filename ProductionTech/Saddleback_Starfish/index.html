Production Technician Pathway Planner

For Starfish Signs & Graphics and Saddleback College, built on DAS file #99764

Pick an employee, change the courses, and see right away whether the plan still meets the hour minimums and has a course behind each of the six competencies. A plan that does is a valid pathway, so there is room to swap.

Courses by Year

Move a course to another year or remove it. Use the catalog below or the alternatives beside each competency to add one.

Competencies

Apprentices are signed off on each one on the job. Courses give the related instruction behind it. You can change which courses cover each competency here or in the catalog.

Course Catalog

Descriptions are from the Saddleback course sheets. Hours are weekly lecture plus lab hours times 16 weeks.

How to read the fit. A solid chip means the course description supports that competency. A dashed chip means the course likely covers it but its catalog text does not say so, so it needs a check with Saddleback faculty. The fit is a first pass for the college, employer and LAUNCH to confirm.

Draft for discussion. Competencies and hour rules come from the DAS standards (Attachment B-2) and the program occupation summary.
